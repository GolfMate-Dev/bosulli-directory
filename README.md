# bosulli.eu project directory

This static directory is separate from the applications it links to. Edit the
Projects list in index.html whenever an approved project hostname changes.

Keep entries without an operational HTTPS site labelled Coming soon, without a
link. Once the target resolves and the expected HTTPS and access checks pass,
make its heading an HTTPS link and show its access type. Remove retired entries
when their hostnames are withdrawn. List only intended hostnames; never publish
credentials, invite links, addresses of internal services, or private data.

The directory is a public index with search indexing discouraged. Project
authentication is handled at each linked site.
